# Tic Tac Toe Game

A simple Tic Tac Toe game developed in C++.

## Features

- 2 Player Game
- X and O markers
- 3×3 game board
- Winner detection
- Draw detection
- Invalid input handling

## Language Used

- C++

## How to Run

Compile the program using:

```bash
g++ tic-tac-toe.cpp -o tic-tac-toe
